# Synthetic corpus

Everything in this directory is **synthetic**. It contains no production data,
no employer or client data, and no real hostnames, IP addresses, or people.

Real CVE identifiers are used and are expected: they refer to genuine public
vulnerability records so that enrichment against CISA KEV, NVD, and EPSS
returns meaningful results.

Generated by `python -m scripts.seed`. Do not hand-edit generated files.

## Enrichment cache

`cache/` holds responses from CISA KEV, NVD, and EPSS. Each source is queried
once and cached so that a demonstration never depends on a third-party API
being reachable at that moment.
